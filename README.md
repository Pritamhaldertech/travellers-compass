# 🌍 Traveller's Compass

A web application to discover tourist attractions in any city and save your favourites. Built for the DLBCSPJWD01 course project.

## ✨ Features

- 🔍 Search for attractions by city (Paris, London, Tokyo, Rome)
- 📝 View attraction name, description, and image
- ❤️ Save favourites to browser LocalStorage
- 🗑️ Remove favourites from your list
- 📱 Fully responsive design (mobile + desktop)
- ⚡ Backend API served with Node.js + Express
